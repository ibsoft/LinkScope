# Optional offline ClamAV package

Place a matching official x64 MSI and detached OpenPGP signature here as `clamav-latest.msi` and `clamav-latest.msi.sig` before building or alongside the built Setup executable under `deploy`. Both files are required together. Setup authenticates staged bytes against the pinned Cisco Talos release key using an independently installed trusted GnuPG. Legacy SHA-1 signatures require an additional independent SHA-256 match. If both files are absent, V69 automatic Setup can acquire the official stable package pair online, subject to the same signature requirements and official asset digest verification. No vendor binaries are distributed in this source archive.
