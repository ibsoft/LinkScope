# Endpoint Protection V34

## Effective watcher coverage
The dashboard now reports the effective provider, not a raw local watcher exception. A fresh backend `Watching` state and verified privileged watcher show real-time monitoring active via automatic SYSTEM fallback. Local initialization failures remain in expandable technical diagnostics. A stale snapshot, uncovered root, initialization, journal-only coverage, or disabled policy is not presented as verified live watching. Journal availability is explicitly separate from scan completeness. Existing watcher coverage and security warning logic is preserved; this change does not repair the local watcher itself or guarantee event delivery.

## Endpoint history reset
Sign in as an administrator. On Endpoint Protection, select **Endpoint history reset (Settings)**, or open Settings and expand Endpoint Protection. The destructive reset control is near the top. Direct link: `/settings#endpoint-history-reset`. The existing reveal handler opens the containing accordion. The reset requires the saved endpoint policy to be enabled, no unsaved settings edits, and explicit confirmation. The existing V33 admin-only, CSRF-protected endpoint reset implementation is retained. Active findings, quarantine evidence, canaries, protected paths, pending work, non-endpoint history, and administrative audit records are retained. Historical scan activity and resolved endpoint findings are cleared, and a fresh baseline is scheduled. Cancel sends no reset request. Reset & rescan on the dashboard is a different, non-destructive operation.

## Build and verification
Extract into a clean folder and run `Rebuild-VisualStudio.cmd Release` on Windows. Deploy both services with the generated installer. Refresh the browser after the upgrade (Ctrl+F5). Versioned JS/CSS asset aliases are used on both relevant pages to avoid cached old UI. Check fallback status, expandable diagnostic text, and reset confirmation/status in Settings. Test real create/change/delete events in each configured root, not merely watcher registration. Do not use a reset to hide actual coverage gaps.

See ENDPOINT-TEST-RESULTS-V34.txt for portable SQLite, browser and source checks, including two outstanding failures (CSS assertion and missing Font Awesome notice in the source package). Windows compilation and live service/ClamAV integration were not performed. Release candidate only. No change to scan policy or runtime watcher access permissions.
