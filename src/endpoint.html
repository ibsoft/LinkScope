STEP 01 / 06 · PREREQUISITES

Prepare your test environment

Start here. Choose a disposable application directory, not the root of a production application. Add it to the saved protected paths, explicit response paths and Test Center directories in Settings, then enable real-time monitoring and process correlation. Only explicitly saved Test Center directories are available for live tests.

Which mode should I use?

Monitor detects only. Protect adds confirmed-malware quarantine. Contain also requires explicitly approved executable paths and verified malicious process identity. You can validate auditing in Protect mode; do not enable Contain merely to make a status green.
