# V58 — Guided Containment Test Center

UI-only redesign of V57. Six selectable stages, previous/next navigation, one visible stage, responsive navigation and per-stage results. The first stage explains the saved policy and prerequisites; the second runs existing read-only diagnostics with an empty marker; the third retains the existing confirmed live audit probe; the fourth submits a fresh external lab marker using the same read-only API and reports writer and process identity separately; the fifth contains explicitly manual isolated canary/quarantine/containment exercises; the sixth summarizes session status and recent historical evidence separately. Navigation never implies successful validation. Results reset on page reload; no persistence or new API. Production response, ACL provisioning, signature policy and scanner are unchanged. Existing API administrator/CSRF checks remain authoritative.

The external writer requires both matching writer and process identity Pass results. The audit probe's own result remains a self-writer test, not external writer or containment verification. Manual exercises remain unverified. Readiness is live telemetry, not a certificate. No new privileges or automatic live response introduced. No native Windows compilation or service execution performed; Chromium tests use simulated API responses.

Rebuild using Rebuild-VisualStudio.cmd Release and upgrade using Setup. Open Endpoint Protection → Test center. Start at Step 01 and advance through the stages. Existing policy and incident history are retained by the unchanged upgrade path.
