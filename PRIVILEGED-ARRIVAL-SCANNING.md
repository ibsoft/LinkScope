# V21 — restricted SYSTEM-assisted scanning and priority arrivals

## Upgrade and configure

1. Extract the complete source ZIP in a clean directory, rebuild Release (`Rebuild-VisualStudio.cmd Release`), and use Setup → Upgrade / repair. Both services must be upgraded together because the USN pipe protocol is now v2. The existing journal checkpoint and pending queue are retained; the arrival table is created automatically.
2. Verify `Get-Service LinkScope,LinkScopeUsn` from an elevated PowerShell. Main service stays LocalService; the existing journal helper stays LocalSystem. No profile ACL grant is required for the new fallback.
3. Set monitored paths to the actual local folders of interest, e.g. `C:\Users\<username>\Downloads`, `C:\Users\<username>\Desktop`, or whole fixed drives `C:\` and `D:\`. Preserve canary paths and real-time monitoring. Copies from a network share or other local folder are monitored at the destination on a configured local disk. This does not monitor remote shares themselves or identify the origin of a file.
4. Open Endpoint Protection, select **Reset & rescan**, confirm. It resets session scan counters and retires operational scan warnings, not malware/canary findings, incidents, quarantine evidence, historical activity, USN checkpoints or queued events. New or unresolved coverage warnings will reappear. Acknowledge previous alerts separately if desired.

## Access boundary

The existing LocalSystem helper has a separate local named pipe with a service-SID ACL. On a LocalService metadata/read access denial, it independently loads the saved protection scope, permits only configured fixed local paths, refuses reparse paths and verifies final file handles, reads only, and returns bounded metadata/hash/entropy/ClamAV verdicts, not raw file bytes. File contents are streamed only to standard port 3310 with registered standard ClamD service, protected installation path, loopback-only listener, verified connected PID and live image checks. The main service retains its existing automatic response restrictions and is not promoted to SYSTEM. A compromised web process must not be granted unrestricted file reads. This is not a kernel minifilter and does not override all ACLs, encrypted files, locked files, hard-link guards, reparse points, or scan size/traversal limits. A directory with more than 8192 direct children on the privileged fallback is explicitly marked incomplete. The 100,000-entry full-scan cap remains. Native security review and runtime testing are required before production deployment.

USN FILE_CREATE and RENAME_NEW_NAME records upgrade pending paths into an arrival table in the same transaction as the checkpoint. Downloads and arrivals receive priority; older work is also serviced. Existing watcher create/rename priority and bounded retries remain. Existing user directories with an unavailable watcher may be monitored by a live NTFS journal; watcher fallback status and other coverage warnings are still reported if necessary. User/network copies that overwrite existing files are covered by ordinary change events and recent-event scheduling. Remote-only filesystem changes are not covered. The application cannot guarantee immediate scans while a current scan is blocking, and other antivirus software may intercept files first.

## Windows acceptance tests (not executed in the packaging environment)

- Compile Release and confirm both services are running. In Endpoint Protection verify C: Journal Live and actual scope includes the destination. Confirm SYSTEM-assisted checks increments for protected paths. Inspect coverage details for any remaining failures.
- In Monitor mode, run the installed executable as administrator with `--endpoint-engine-self-test`; verify it reports EICAR FOUND. Then use an official EICAR test file, if it remains present after any other endpoint security product acts, download it into a monitored Downloads folder, copy into monitored Desktop and copy from an authorized network share to a monitored local folder. Check live activity and malware findings. If the file is absent, do not disable other endpoint protection simply to pass this test.
- Run `& "$env:ProgramFiles\LinkScope\LinkScope.exe" --endpoint-scan-file "$env:USERPROFILE\Downloads\eicar.com.txt"` (adjust filename). Report the exact result. A FOUND verdict must create a malware finding; a missing file or access/transport error is not a clean result.
- Verify only related dashboard cards change color; zero active malware and unrelated healthy canaries do not inherit an access warning. Test reset with existing canary/malware findings and confirm they remain active. Test viewer account cannot request reset.

Portable checks passed for the new broker integration, queue migration, SQLite rollback and deduplication, priority arrival handling, source delimiter checks, and JavaScript syntax. A pre-existing CSS assertion in `validate_endpoint_layout_updater.py` still fails after the actual rendering checks pass. Windows C# compilation, native privileges, ClamAV protocol/peer verification, actual EICAR detection and performance are not verified here.
